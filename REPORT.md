## Exercises

1. **Horizontal alignment:** заголовок `Campus Card` и Student ID выровнены по центру. Строки расписания остаются выровненными слева; три колонки внутри них разделены через `weight` и фиксированную ширину времени/аудитории.
2. **SpaceBetween vs Center:** переключатель «Распределить кнопки по краям» меняет расположение нижних действий между `Arrangement.SpaceBetween` и `Arrangement.spacedBy(16.dp, Alignment.CenterHorizontally)`. Для итогового экрана оставлен режим `SpaceBetween`, потому что кнопки занимают левый и правый края строки.
3. **Top vs CenterVertically:** переключатель «Выровнять время по центру строки» меняет вертикальное выравнивание всех строк расписания. `Top` заметнее, когда название занятия переносится на вторую строку: время прижато к верхней строке текста. `CenterVertically` ставит время примерно посередине высоты многострочного названия.
4. **Modifier.weight:** название курса получает оставшуюся ширину между временем и аудиторией. Длинное название ограничено двумя строками с многоточием, поэтому аудитория остаётся видимой.
5. **Nested layout refactor:** экран использует `ProfileHeader(name: String, status: String)` и `ScheduleRow(time: String, title: String, room: String, centerVertically: Boolean = false)`.
6. **Arrangement.SpaceBetween на экране:** внешний `Column` использует `Arrangement.SpaceBetween` и занимает доступную высоту. Заголовок профиля остаётся сверху, действия располагаются ниже расписания, а свободное место распределяется между блоками. Для карточки это подходит, пока содержимое помещается на экран; при нехватке высоты экран прокручивается.
